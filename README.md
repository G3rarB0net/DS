# Software Development Assignments - Degree in Computer Engineering (UGR)

This repository contains the assignments completed for the **Software Development** course in the Degree in Computer Engineering at the University of Granada (UGR).

Throughout the course, we focused on the study and implementation of **software design patterns**, principles of **software architecture and maintainability**, and **quality assurance** through testing — mainly using **Python** and **Flutter**.

---

## Assignment 1: Design Patterns 

In this assignment, we implemented a set of exercises to practice the identification and application of classic software design patterns. The main goal was to understand their role in creating modular and extensible software.

The implemented patterns included:

- **Strategy**
- **Abstract Factory**
- **Intercepting Filter**

---

## Assignment 2: Introduction to Flutter and Maintenance Tasks

This assignment introduced **Flutter** as a framework for cross-platform mobile development. It was divided into two parts:

- Practical exercises applying design patterns in **Dart/Flutter**.
- Adaptive and perfective maintenance of the **Interceptor Filter Pattern activity** from Assignment 1, adapted to the Flutter environment.

---

## Assignment 3: Unit Testing in a Banking App 

In this practice, we developed a simple **banking application prototype** in **Flutter**. The main objective was to implement a set of **unit tests** to verify the correct behavior of the application, ensuring functionality through **test-driven development** principles.

---

## Assignment 4: Full-Stack Task Manager App (Flutter + Ruby on Rails)

In this final assignment, we built a complete mobile application in **Flutter/Dart**, connected to a **Ruby on Rails** backend exposing a **RESTful API**. The backend used **SQLite** as the database engine.

The app functions as a **task manager**, allowing users to:

- Create and manage tasks
- Share tasks with other users who have a friendship link
- Synchronize and store data through the API
